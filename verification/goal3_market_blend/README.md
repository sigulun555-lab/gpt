# totoGOAL3 v2（市場ブレンド）— 試算のみ、本番未適用

ユーザー依頼で、Claude側（`sigulun555-lab/toto-lab` PR #17）と同じ市場ブレンドの
試算を、このリポジトリの`model.js`の予想（`data/predictions.json`、本番、提出済み）
に対しても行ったもの。**`model.js`自体は変更していない**（`predict()`も
`backtestGoal3()`も無改修）。このディレクトリの関数は追加のみで、
`auto_pipeline.js`からも呼ばれていない。

## 市場データ

toto ONE（totoone.jp）の購入割合、第1666回GOAL3、ユーザースクリーンショット
取得時刻 2026-10-28T16:20+09:00。公式toto-dream.comページそのものではない点に注意。

## ブレンド方式

`goal3_market_blend.js`の`blendGoal3WithMarket(probs, market, weight)`：
4ブラケット[0,1,2,3+]の確率ベクトルをそのまま重み付き平均。

```
p_v2[k] = MARKET_WEIGHT * market[k] + (1 - MARKET_WEIGHT) * p_v1[k]
```

`MARKET_WEIGHT = 0.7`は、第1665回の1X2市場ブレンド（Claude V2ロジック）からの
暫定流用。GOAL3用に独立検証した値ではない。

## 注意：チーム名の表記ゆれ

試算中に見つかった点として記録: このリポジトリの`canonicalHome`は
「横浜F・マリノス」（半角F）だが、toto-lab側の`data/teams.json`は
「横浜Ｆ・マリノス」（全角Ｆ）。市場データの辞書キーをこちらのリポジトリの
表記に合わせて修正して試算した。両リポジトリの正規化辞書が完全には一致して
いない可能性があるため、今後の統合時に要確認。

## 第1666回の試算結果

`round_1666_v2_trial.json`参照。6サイド中4サイドでv1とv2の予想ブラケットが一致、
2サイド（横浜F・マリノスのホーム、広島のアウェイ）で不一致。Claude側の試算
（toto-lab PR #17）では6サイド全て一致していたため、v1モデル自体の違い
（shrinkage MLE vs 直近12試合比率）によって市場ブレンドの効き方も変わっている。

## 修正履歴

- 2026-10-28: GPTのレビュー（toto-lab PR #17コメント）を受け、
  `blendGoal3WithMarket()`を修正。toto ONEの表示%は丸め誤差で合計
  97〜99%になっていたが、以前はブレンド後にまとめて正規化していた
  ため、サイドごとに実効的な市場ウェイトがずれていた。市場ベクトルを
  先に合計1へ正規化してからブレンドするよう修正。結果への影響はごく
  小さく、6サイドの予想ブラケット（v1 vs v2の一致/不一致）は変わらない。
