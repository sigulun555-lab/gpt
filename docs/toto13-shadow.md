# toto13 T1 shadow runner

This folder is an isolated research path. It does not import or modify production `model.js`, `data/predictions.json`, market weights, or existing prediction logs.

## Variants

- **V0 control:** T1 Poisson with shrinkage (k=6), last 12 team matches.
- **V1 candidate:** identical model with only shrinkage changed to (k=10), last 12 team matches.
- **Baseline reference:** (k=0), last 12 team matches.

All three use the same history snapshot, fixture list, strict chronological cutoff, and 0..10 score grid. No Dixon–Coles correction, draw boost, or market blend is applied. This isolates the single shrinkage-constant change.

## Input fixture format

Pass a JSON document containing exactly 13 fixtures. Do not use a 3-match totoGOAL3 fixture file. Each fixture date must be date-only `YYYY-MM-DD`, so same-day history is excluded.

## Run

```sh
node scripts/run_toto13_shadow.js path/to/round_fixtures.json shadow/toto13/predictions/round_XXXX_<unique>.json
node --test tests/toto13-shadow.test.js
```

The output destination is restricted to a new `.json` file under `shadow/toto13/predictions/`. Existing files are never overwritten. The runner records SHA-256 hashes for history and fixtures, the three probability vectors, xG, per-team prior counts, unknown-team warnings, and GitHub Actions run metadata when available.

## Timestamp and scoring evidence

`createdAt` is generated by the runner and is not, by itself, independent proof that the prediction existed before the deadline. For a prospective score, preserve and verify:
- the artifact's `createdAt` and SHA-256 digest;
- GitHub Actions `workflowRunId`, attempt, commit SHA, and run creation/completion times;
- the artifact creation time and immutable artifact identifier;
- the official deadline and official match results.

A Git commit timestamp alone is not sufficient evidence. Do not score a match unless the prediction artifact is demonstrably available before the applicable deadline and the result is officially verified.
